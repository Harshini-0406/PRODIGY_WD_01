# PRODIGY_WD_01

## Responsive Landing Page

This project was developed as part of the **Prodigy InfoTech Web Development Internship (Task-01)**.

### Project Overview

The goal of this task was to create a responsive and interactive landing page with a fixed navigation menu that changes style on scroll and provides an engaging user experience through modern UI design and animations.

### Features

* Responsive Landing Page Design
* Fixed Navigation Bar
* Scroll-Based Navbar Effects
* Hover Animations
* Modern Hero Section
* Animated Statistics Counter
* Feature Cards
* Contact Form
* Smooth Scroll Animations
* Mobile-Friendly Layout
* Glassmorphism UI Elements

### Technologies Used

* HTML5
* CSS3
* JavaScript

### Learning Outcomes

Through this project, I gained practical experience in:

* Building responsive web layouts
* Implementing modern UI/UX principles
* Using CSS animations and transitions
* Working with JavaScript DOM manipulation
* Creating interactive user experiences
* Managing projects using Git and GitHub
